Detailed Description

Manages the set of A2DPEncoder instances registered via BluetoothA2DPSource::add_encoder(), delegates encode operations to whichever one matches the codec negotiated with the connected sink and packs the encoded frames into A2DP media packets that are sent with esp_a2d_source_audio_data_send().
