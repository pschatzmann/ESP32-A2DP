Detailed Description

SBC encode support for the managed A2DP encoder framework: wraps an audio_tools::SBCEncoder (codec-sbc / arduino-libsbc), advertises the SBC SEP capability and configures the encoder (subbands, blocks, allocation method and bitpool) with the parameters negotiated with the sink. Register it via BluetoothA2DPSource::add_encoder().
